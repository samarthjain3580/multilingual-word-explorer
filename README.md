# Multilingual Word Explorer

A beginner-friendly full-stack web application that lets you enter a word or phrase and translate it into **multiple languages at once**.

## Tech Stack

- **Frontend:** React, Vite, Axios, React Router
- **Backend:** Node.js, Express
- **Database:** PostgreSQL (Phase 11+)
- **Translation:** External API via backend (Phase 6)
